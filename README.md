# CSV handoff check — fictional sample

A four-record demonstration of a report-only check for a small-business product, stock or supplier-reference CSV. All input records are fictional. This is not client work, an order, a testimonial or evidence of a successful import.

**Service: A$69 total. Supplier: Jai Malkiewicz, ABN 64 936 517 906. No GST charged.**

For one non-sensitive UTF-8 CSV up to 2,000 parsed data records, 100 columns and 10 MB, you receive a readable report, a position-only issue list, an explanation of the findings and one same-scope recheck. You choose the rules: up to three required fields, one unique key of up to two fields, two plain-decimal fields and two ISO date fields. The service uses an offline checker and AI-assisted interpretation. Your original file stays unchanged. Human review is not claimed.
